# 产品意图

Govel 面向 AI Agent 提供中文长篇小说的设定、规划、章节与修订工具。作者通过 AI 客户端中的对话提出意图、审阅内容并作出批准；模型负责构思、正文、语义判断与工具调用；Govel 保存项目状态、检查已登记的约束，并执行受控写入与事务恢复。

日常创作以对话为主，减少作者手动执行命令和维护文件的负担。Govel 不提供独立的图形写作界面，也不内置模型；通过 MCP 或 CLI 接入支持本地工具调用的客户端。客户端与模型的推荐用法见 README，不构成引擎的固定依赖。

模型不熟悉命令时通过 help 学习，了解后直接调用。项目查询、准备、修改与提交应由公开工具完成，不让模型通过读源码、解析内部 JSON 或写专用脚本弥补日常操作入口。帮助只负责发现与参数说明，不替代模型的文学判断，也不产生执行授权。

MCP 与 CLI 提供相同的公开项目能力。新建、追加原稿、章节拆合、外改采用和备份恢复均应能沿工具完成，不要求作者或模型为某本书编写专用脚本。采用外部编辑结果时，可通过系统确认窗口取得独立作者确认；这不是独立的图形写作工作台。

公开核心可在没有参考资料的情况下运行。个人圆桌和知识库以 `local/roundtable.md`、`local/knowledge/` 为直接入口；私人圆桌非空则使用，否则使用通用版。题材词表和专用材料可由本地 Provider 接入。公开代码不附带参考数据集，使用原创中性样例验证接口。

同一事实只有一处权威来源。引用与读取回执不证明理解；机械检查不证明文学质量；模型结论不替代作者批准。未完成事项只影响其实际依赖范围，恢复时保留有效成果。

仅支持当前项目格式。外部稿件经人工整理后导入，不自动承接旧身份、批准或正文归属证明。

原稿导入由工具完成分章候选、身份分配、正文保存与项目创建。作者校对分章和内容取舍；模型不为每本书编写初始化程序。确认导入只接纳本次原稿，设定提取、规划和文学审查保持独立待办。

导入后的资料提炼、回溯梗概、人物关系、风格和摘要由 AI 在会话内实际阅读后完成，工具负责引文、身份、版本和事务。作者集中处理歧义与正式采用；回溯审阅通过后可将已写原稿作为前章历史接续，不补造历史阶段 A/B。数据完整性与创作就绪度分别报告，零关系或空规划目录不能单独证明资料缺失。
