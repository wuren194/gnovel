# 章节审阅

逐项核对事实、人物知识、行动因果、空间时间、角色表达和已约定文风。保留问题定位与依据，区分成立的缺陷、待核实判断及可选建议。G-EXPANSION.md 与 G-OVER-ORGANIZATION.md 的两个方向同时成立。

对风格诊断的每组候选，检查原句和相邻段是否提供必要信息、是否重复、是否符合视角和声纹。可以说明理由后保留；需要修改时只处理已有证据支持的范围。正常心理陈述、功能性对照、有效排比和完整结尾不因形式命中而自动成为缺陷。不得把启发式分数当作文学质量或生成来源的证明。

完成判断使用当前阶段 B 表单与实际候选；题名、连续性和事实交接按 CHAPTER-PIPELINE.md 处理。语义结论不授予正式采用。
