# 节奏与段落判断

Planner 在当前章 owner、`contentRole=plan` 片段中声明节奏与篇幅要求。Writer 使用已获阶段 A 批准的当前 `sourcePlanHash`；Editor 以当前正文 evidence 核验。阅读快照与 Markdown 导出不承担计划修改或批准。

## 1. 句长与段落

句长跟随动作、观察、对话和思考变化。段落围绕当前叙述需要组织；单句段可以承担强调、打断、停顿或收束，也可以来自作者已确认的文风。

S-08/S-11 等形式特征由机械检查提供定位，阈值以注册表为准。修订须处理重复结构或信息分配问题，不能为消除命中删除必要主语和因果。

**S-11 修复纪律**：需要时换主语或重构句式，让行动主体和承接关系保持清楚。禁止靠删除或省略主语掩盖实际重复；同样不能为了变换句首而加入无关动作。

叙事与对白的停顿按各自用途判断。机械豁免以规则卡为准，豁免不替代对可读性的审阅。

## 2. 场景节奏与波形

- 开场使读者能辨认当前空间、人物活动或需要关注的信息。
- 中段的行动与信息应有反馈，不持续重复同一功能。
- `stateChange=true` 的场景核对实际变化及后果。
- `stateChange=false` 的场景按信息、准备、休整、关系校准或其他已声明作用判断，不强加转折。
- 章末完成当前计划的落点，保留作者选择的收束方式。

## 3. 密度与重复

细节是否保留取决于其信息与表达作用，不要求每个细节出现后立即工作。准确的词可以重复，短窗口内的同义词轮换由机械结果和语境共同判断。

相似场景再次出现时，检查其目标、阻力、信息、关系条件或意义是否有变化；有意重复可以承担对照或回声，不按次数直接判错。

## 4. 镜头速度（放慢与快进）

观察距离与叙述速度服从当前场景目标、情绪密度、作品文风和篇幅预算。关键选择、信息取得和关系变化可以展开，过渡也须保留读者理解所需的条件。

Planner 如已声明放慢节点或微距锚点，Writer 应落实该节点的具体过程，Editor 核对是否兑现。没有声明时，不强制某类动作或外貌描写始终慢于其他内容。

放慢应增加尚未呈现的信息；快进不能跳过承重因果。感知细节受当前视角、位置和时间限制，不能描写人物当时无法感知的内容。

扩写的授权范围与预算不匹配处理见 `G-EXPANSION.md`。节奏充分和组织不过满同时验收，反误判要求见 `G-OVER-ORGANIZATION.md` §4。
