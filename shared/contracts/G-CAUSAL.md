# G-CAUSAL：场景因果与状态变化合同

因果计划位于当前单一真源的 plan 片段与章节合同中，不另建平行计划工件。场景内因果链由 Writer 现场推演、由正文承担；机械门给出形式证据后，Editor 十身份阶段 B 以正文证据复核。

## 章节模式（chapterMode）

`chapterMode` 是离线诊断的调用参数；章节计划中的模式由当前章节合同声明。可用枚举及机械含义通过源 schema、规则卡与注册表查询，不把诊断模式当作题材要求。

| 模式 | 使用范围 | 核对重点 |
| --- | --- | --- |
| `plot` | 叙事与任务推进 | 人物目标、信息、选择与后果。 |
| `buildUp` | 准备与铺垫 | 当前信息和条件如何为后续发展提供依据。 |
| `mixed` | 同章包含不同场景重点 | 按明确选中的场景段落应用对应检查。 |
| `peakScene` | 当前计划中的重点场景 | 核对已声明的展开要求，不预设动作或关系类型。 |

## 必需因果链与场景模式

场景内因果由 Writer 展开，Editor 依据正文核对。以下结构用于查缺口，不要求源计划逐场景机械填满所有节点：

1. **任务驱动场景**：核对目标、阻力、尝试、反馈、选择与后果；缺失环节若影响结果成立，明确指出证据。
2. **关系或情绪变化场景**：核对变化由什么当前条件与选择承担。动作、对白、内心和静默均可成为依据，不强迫套用任务解题流程。
3. **氛围与过渡场景**：按信息、空间时间衔接、准备或休整等实际作用判断，不强制产生新事件或状态变化。

主线剧情预期状态变化由 Planner 在源计划登记 change intent（本章级，写在十身份讨论【决策】与【遗留】），由正文承接。最终 Editor 审校须对每个 intent 给出 `fulfilled | superseded | not-realized` 及真实 evidence。

## 变量分离

- 支配方式的作用范围不得超过其资源或规则来源。
- 来源失效后不能靠气质继续生效。
- 局部交付或单次胜负不自动改变长期 dominantRole。
- 已确定的关系变化应落实到实际源记录和计划；局部结果不自动扩大为长期关系事实。
- 正文只有结论、没有 attempt/feedback/choice 时，Editor 十身份阶段 B 必须报 S1/S2。

## 关系依据与选择代价

本章以一方接受另一方安排、持续合作或关系位置改变为关键因果时，Planner 在当前章计划片段的
`chapterContract.relationshipCausality` 声明待审依据。字段与枚举由源 schema 查询说明，
使用方法通过当前 `source schema` 与 `source chapter-plan` 查询。不在 `pairs`、独立台账或阅读导出里另存同一计划。

- 实际能力按已经登记的事实判断。体型、外观和第一印象不能自动推出力量、判断力或行动能力。
- 明确拒绝与接受各自的可行选项、代价及角色为何选择当前路径；代价可以是现实损失、承诺、
  个人目标或关系需求，不能靠“他自然会配合”省略关键一环。选择自愿成立时，不强迫补造威胁。
- 依据只在声明的范围内有效。单次胜负、局部交易不自动取得长期控制；依据改变后须说明
  仍然成立、新依据接替，或约束解除。约束解除后也允许关系结束，不强迫续上另一种控制。
- 阶段 A 对每条声明给出当前计划引文和判断；阶段 B 对同一项给出当前正文引文，复核选择和
  变化的形成过程。十身份在同一会话内执行，复用现有审校工件与作者批准流程。
- 工具检查形状、源引用、材料绑定和判断是否填写，不计算人物“应当”服从，也不把通过形式检查
  当作文学因果已成立。每章都须显式完成下述覆盖判断；空声明不能代替“不适用”。
- 计划需要说清判断依据，正文只需完成关键形成关系；不得为了交齐表单逐项解释或重复证明，
  与 `G-OVER-ORGANIZATION.md` 同时执行。

## 每章覆盖与人物生活安排

章节合同 `behaviorCoverage` 对 relationship／living 分别声明：适用、不适用、未评估或缺材料。
具体枚举和字段读 source schema；未评估、缺材料不能完成阶段 A。覆盖理由与引文复用席4，
出现承重生活安排时激活席9。B 独立重扫当前正文，在原 logic／relationship／continuity 席分工，
不能只遍历 Planner 声明；A 漏掉而 B 发现的条目以 `behaviorReviews.origin=prose` 留证。

只有以下触发项进入 `livingArrangements`：首次把安排声明为长期常态、明显消耗时间或持续资源、
排除已经成立的可行选项、把一次例外变成长期义务或关键关系条件。其他普通动作不用逐项填表。
实际基线复用已有 FieldDefinition、Attribute、Fragment 与时间/依赖机制：工作与休息时段、
居住安排、资源是否可用、照料分工、稳定能力和偏好。按需登记确切依赖；未来安排仍是 plan。
职业印象不是事实，未知不是没有。没有依据时保留未知或缺材料，不能编造常识资产包。

对实际触发项检查：

- 时间预算同时容纳工作、交通、休息和照料；持续财务与物质消耗有可用来源。喜好与自愿能解释
  选择，不能消除硬时间冲突、交通耗时或客观身体限制。
- 已有住所、服务、亲友与求助/离开选项是否仍然可用。主动不用资源可以成立，须有当前或前文
  已成立的动机；不能无故抹掉选项来迫使同居。求助、离开和拒绝沿用关系选择代价审查。
- 外部联系和职责是否收到相应反馈：缺席工作、失联或持续照料对既有安排有什么影响。
  公开行为另查谁能发现、通过什么渠道传播及影响范围；不强制惩罚，也不把传播后果全塞进拒绝代价。
- 影响关键结果的技能须有前置依据；临时动用不曾成立的能力不能靠身份标签补证。
- 跨章时距、伤情、治疗与行动限制复用章节验收清单；不另建第二套身体或交通数据库。

普通住宅、自愿做饭、能力足够但主动分工都可以成立。已成立理由跨章复用即可，不要求正文每章
重新解释；有意暂不揭示与信息未知须保持叙述边界，不自动判错。审校模型判断合理性，机器只核
显式覆盖、当前绑定、确切引用与未处置项。
