# 角色口吻与台词印记

声纹帮助人物在具体处境中保持连贯，不要求每个角色固定使用一种句长、语气或情绪强度。

## 1. 声纹资料

人物的声纹摘要归当前人物实体的属性或片段；结构化 `voiceProfile` 是可选对象。先查询人物稳定 ID 与现有内容，修订已用声纹按 `G-SINGLE-SOURCE.md` 经受审提案、预览和批准提交。

本章如何使用声纹归本章 plan 片段，并登记所需依赖。读取投影不取得设定写入权。

```json
"voiceProfile": {
  "syntaxPreference": "解释步骤时按顺序说，闲聊时常省略已知主语",
  "catchphrases": ["先记下来", "明天再核对"],
  "bannedPhrasesForRole": ["本角色不使用的示例称呼"],
  "sentenceLengthTrend": "varied",
  "punctuationHabit": "停顿服从实际语意"
}
```

资料可以描述词汇、称呼、句式、表达目的和随处境变化的说话方式。禁止词来自作者明确的角色约束，不从人物职业、外形或关系标签自动生成。

## 2. 对白核对

- 去掉说话人标记后，检查较长对话中的选择与表达是否仍可区分；不要求每句短答都有独特标记。
- 对照当前人物知识、目的和关系，核对称呼与表达意图是否相容。态度变化应有情境依据。
- 确认、解释、直接表达和沉默都可以成立。潜台词是可用方法，不是每句话的必填层。
- 叙述中的动作和说话标记用于澄清主体或呈现反应，不以固定动作替代人物表达。

## 3. 机械证据与归属

`scripts/check_voice_lexicon.py` 检查 `voiceProfile.bannedPhrasesForRole` 和注册表 `voice.globalBannedInterjections`。全局词面规则只代表该规则的适用要求，不替作者定义所有角色的口吻。

命中角色禁词报 `OOC_VOICE_DRIFT`：直接归属依据成立时为 error；动作、回溯或轮次推测等弱依据仅报 warning，单独出现时推荐 `review_advisory`，随报告展示并交 Editor 核实，不强制返修。不确定到无法选定人物时保留归属覆盖记录，不为某个角色制造词面违规。既有语义审校中已经成立的问题，不能因本次机械归属较弱而自动降格。

词面证据不能证明潜台词、人物意图或读者辨识度。Editor 阅读当前材料后给出语义结论；候选变化后重新核验实际影响。
