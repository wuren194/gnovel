# 文风与表达

以作者已确认的作品文风为依据。未声明的风格选择保留为候选，不能从参考材料推导作者偏好。

人物的观察、用词和判断受其身份、经历与当前知识限制。动作有起点、对象和结果；对话由当前目的及关系推动。细节应帮助读者理解场景，不以统一的感官密度或修辞数量替代文学判断。

场景节奏依计划分配篇幅和观察距离。关键选择要有足够展开，过渡保留必要信息；不强迫所有场景采用同一种速度。人物状态跨段承接，变化有事件依据。

编辑先区分明确缺陷与可选表达。处理矛盾、缺失因果和已约定要求；对于同样成立的表达方式，保留原文并给出建议。组织过满及其反误判边界见 `G-OVER-ORGANIZATION.md`。

机械规则与阈值通过当前注册表读取。题材专用规则由显式启用的本地 Provider 提供，未装载时不得假称已检查。
